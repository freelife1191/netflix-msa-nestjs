# Part 17. Pagination

## Pagination 특징

- 데이터 분할: 큰 분량의 데이터를 분할해서 다루기 쉽게 부분적으로 불러 올 수 있다
- 네비게이션 컨트롤: 다음 페이지, 이전 페이지등 기능을 통해 쉽게 페이지 이동이 가능하다
- 균일한 데이터 규격: 요청과 응답이 균일한 규격으로 제공되어 예측하기 쉽다
- 상태 유지: Pagination 요청 자체에 상태 정보가 존재한다. (e.g. 몇번째 페이지)
- 퍼포먼스 최적화: 한번에 필요한 분량의 데이터만 불러오기 때문에 퍼포먼스 최적화가 가능하다

## Page Based Pagination

데이터를 페이지 기반으로 나눠서 처리한다  
예를들어서 100개의 데이터를 한번에 20개씩 가져온다면 5개의 페이지로 나눌 수 있다

## Cursor Based Pagination

마지막 불러온 데이터를 기반으로 다음 가져올 데이터를 정한다  
예를들어 마지막으로 불러온 데이터가 20번이었다면 다음 요청은 21번부터 가져온다
